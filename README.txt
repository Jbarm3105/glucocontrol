GlucoControl - aplicación web instalable (PWA)

1. Abre index.html en un navegador compatible.
2. En Android/Chrome puedes usar "Añadir a pantalla de inicio" para instalarla.
3. En iPhone/iPad/Safari puedes usar Compartir > Añadir a pantalla de inicio.

La aplicación funciona localmente y guarda los datos en el almacenamiento del navegador del dispositivo.

Incluye glucosa, medicación, alimentación, actividad, agenda médica, documentos, perfil y exportación de datos.
No calcula dosis de insulina ni recomienda tratamientos.
